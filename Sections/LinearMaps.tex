\section{Linear Maps}

A linear map from $V$ to $W$ is a function $T : V \to W$ with the following
properties.

\begin{itemize}
\item \textbf{additivity} $T(u + v) = Tu + Tv$ for all $u, v \in V$.
\item \textbf{homogeneity} $T(\lambda v) = \lambda(Tv)$ for all $\lambda \in \mathbf{F}$ and all $v \in V$.
\end{itemize}
